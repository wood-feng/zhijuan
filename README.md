# 知卷工作台

知卷工作台是一款本地教学和练习应用。可以从教材整理知识点、审核题目并组卷，也可以直接把已有试题图片转成可作答、可打印的试卷。

## 启动

在项目根目录安装 Python 依赖，再启动桌面版。

```powershell
python -m pip install -r requirements.txt
python app.py
```

Windows 桌面版使用 WebView2。也可以运行 `python app.py --browser`，在本机浏览器使用同一套界面。关闭浏览器后，在终端按 `Ctrl+C` 停止本地服务。项目附带构建好的前端，直接运行无需 Node.js。

## 从图片创建试卷

1. 在「模型与设置」配置支持图像输入的模型和 API Key。
2. 打开「组卷工作台 → 图片转试卷」，上传试题图片，按试卷页序排列后填写试卷名称和时长。
3. 点击「识别并创建试卷」。后台任务完成后，试卷会出现在组卷工作台。系统按图片顺序识别原题，提取题干和选项，并裁切必要的插图。
4. 点击「开始练习」作答，或下载「打印版」。在浏览器打开导出的 HTML，按 `Ctrl+P` 打印或另存为 PDF。

支持 PNG、JPG、JPEG 和 WebP。每份试卷最多上传 12 张图片，单张最多 8 MB，合计最多 24 MB。识别时图片会发送给所选模型服务，可能产生费用。公式、题干和插图可在打印前对照原图核对。

如果从教材出题，可走「资料库导入资料 → 提取并确认知识点 → 生成并审核题目 → 从题库组卷」。离线命题支持填空题，文字和视觉模型可用于其他题型。扫描 PDF 可在资料库按页进行视觉导入。

## 选择练习模式

点击「开始练习」后，选择何时显示答案与解析。选定的模式随练习记录一起保存。

| 模式 | 作答时 | 交卷后 |
| --- | --- | --- |
| 逐题显示 | 点击「提交本题并看解析」后显示本题答案与解析。答题卡用绿色标记答对、红色标记答错、黄色标记待自行评阅。 | 同页查看全部参考答案与解析，客观题自动计分，主观题及无参考答案的题目可自行评分。 |
| 交卷后统一显示 | 答题卡只显示作答进度，可切换题目或保存后续答。 | 同页查看全部参考答案与解析，可自行评阅，也可调整客观题的自动评分。 |

切换题目或点击「保存并返回记录」时会保存作答。交卷后作答锁定，评分仍可保存。

## 批量删除和导出

- **题库**支持批量审核、退回待审核和删除。删除题库中的题目后，已创建的试卷仍使用题目快照。
- **组卷工作台**支持批量删除试卷，以及导出学生版或教师版。删除试卷后，已有练习仍可继续作答、回看和导出。
- **练习记录**支持批量删除和导出。导出含已保存的作答、评分及可查看的答案与解析。删除某次练习后，可从仍在组卷工作台中的试卷开始新练习。

勾选一项或多项后即可操作。「全选」作用于当前筛选结果。批量导出会下载一个 ZIP，每一项都是独立的 HTML 文件。

## 数据与开发

源代码运行时，数据默认写入项目的 `data/` 目录。打包后的 Windows 应用默认使用 `%LOCALAPPDATA%\ZhijuanWorkbench\data`。数据库、原始资料和插图分开保存，备份时请复制整个数据目录。源码运行时可用 `--data-dir` 指定其他目录。模型 API Key 仅保存在当前运行的内存中，重启后需要重新填写。

| 路径 | 用途 |
| --- | --- |
| `app.py` | 启动桌面窗口或本地浏览器服务 |
| `backend/` | 资料导入、图片识题、题库、组卷、练习和导出 |
| `frontend/src/` | React 与 TypeScript 界面源码 |
| `frontend/dist/` | 程序启动时加载的前端文件 |
| `tests/` | 后端回归测试 |

修改前端后，在项目根目录执行以下命令重新构建，再回到根目录运行测试。

```powershell
Set-Location frontend
npm ci
npm run build
Set-Location ..
python -m unittest discover -s tests -v
```
